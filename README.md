🎂 Happy Birthday Wishes Animation

An interactive and aesthetic birthday greeting web application featuring smooth CSS/SVG animations, dynamic candle blow-out interactions, confetti celebration, and ambient background music.

🔗 Live Demo: [https://somueltripura.github.io/happy_birthday_wishes_animation/](https://somueltripura.github.io/happy_birthday_wishes_animation/)

✨ Features
- 🕯️ Interactive Birthday Cake: Smooth multi-layer cake build animation with SVG and glowing candle effects.
- 💨 Blow Out & Relight: Click-to-blow-out candle mechanism with interactive status updates.
- 🎵 Background Music Player: Toggleable birthday music with Play/Pause controls.
- 🎊 Confetti Celebration: Automated burst animations using Canvas Confetti.
- ✍️ Custom Name Customization: Dynamic greeting updater allowing visitors to personalize the wish recipient.
- 🖱️ Smooth Custom Cursor: Fluid interactive cursor trail following mouse movements.
- 📱 Fully Responsive & Modern UI: Glassmorphism card aesthetic styled with Tailwind CSS.


🛠️ Built With
- HTML5: Semantic markup and SVG graphics
- CSS3 / Tailwind CSS: Utility-first styling, glassmorphism effects, and keyframe animations
- JavaScript (ES6): Interactive DOM manipulation, audio controls, and custom particle triggers
- Canvas-Confetti: Dynamic celebration particle effects
